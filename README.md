# Crossword Puzzle

- Players: 1
- Resumable: Yes

## Requirements:

- Render a fixed grid (e.g. 5x5).
- Show across/down clues.
- Allow cell input.
- Check if solution is correct.
- Save progress in localStorage.

## Stretch:

- Offer letter hints.
- Add score based on time and accuracy.
- Show timer on UI (optional).

## Focus:

- Grid rendering
- string checks
- clue-based logic
- user input control.
